Hongtai Screen is an unofficial replacement for the vendor software that ships with Jungle Leopard USB screens (USB vendor ID 33C3, product “MONITOR”, serial/COM port device). It streams JPEG frames to the screen over the serial port, based on community reverse-engineering notes.

Tested on: TXW818-ST7789S-2.8inch-ver, 320x240, firmware 3.1 (USB ID 33C3:7792), Windows 11.

Modes: GIF playlist, live PC stats (CPU, RAM, NVIDIA GPU), clock, single picture or GIF, and stats over a GIF. It also has a tray icon, auto-reconnect and Start with Windows.

Not affiliated with Jungle Leopard or Hongtai. Use at your own risk: a malformed frame can freeze the display (unplug and replug the cable to fix it). Models that need raw RGB565 frames are not supported.
